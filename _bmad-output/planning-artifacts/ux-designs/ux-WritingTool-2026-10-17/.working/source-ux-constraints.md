# Accepted source UX constraints — discovery intake

Source intake only, 2026-10-17. Later resolved decision amendments supersede older partial/open wording. This file records constraints and gaps; it does not approve new designs or finalize canonical UX documents.

## Desktop scope and workspace

- Local, single-machine desktop workspace for Jo's writing. All 12 capabilities and FR-1–49 remain first-release scope. Browser/mobile, cloud sync, collaboration, signing and automatic updates are excluded. [SPEC: purpose/capabilities/constraints/non-goals](../../../../specs/spec-WritingTool/SPEC.md#why)
- Accepted targets: Windows 10/11 x64 `.exe`; macOS 13+ Intel and Apple Silicon `.dmg`; Ubuntu 22.04+/Debian 12+ x64 `.deb`; individually verify Pop!_OS, Zorin and Mint. Include application-menu integration and bundled application/LibreOffice runtimes. Keep live writing folders separate from installation. [DEC-09](../../../../specs/spec-WritingTool/contracts.md#dec-09--first-release-installers-and-platform-targets-approved-2026-10-17)
- Latest conversation approval (2026-10-17, user: “approve and continue”): left project/volume/story/chapter navigation; center manuscript editor; bottom universe timeline with maker/category filters; right tabs for character, faction, plot and decision context. Side/bottom panels resize and collapse, with arrangement remembered. This comes from the latest conversation, not a pre-existing source-document layout or visual-style approval.
- Volumes optionally group stories, one membership per story; volumes/stories can be manually ordered. No enforced volume/story/chapter/word limits. Chapter order differs: missing-start chapters first in creation order; dated chapters by start then creation order. Plot entries use undated-first then chronology, with manual ordering inside undated/same-date groups only. [Volume/plot contracts](../../../../specs/spec-WritingTool/contracts.md#volume-grouping), [chapter tie rule](../../../../specs/spec-WritingTool/contracts.md#same-start-chapter-order--dec-16)

## Writing, navigation and context

- Editable bold, italics, paragraph indents, headings and scene breaks must survive save/reopen and recovery/export. Informational story chapter targets and chapter word targets never limit writing; default chapter word target 2,500; blank unset, whole numbers ≥0 valid. [FR-1/47](../../../../specs/spec-WritingTool/requirements.md#functional-acceptance), [DEC-23](../../../../specs/spec-WritingTool/contracts.md#writing-target-scope-and-validation--dec-23-resolved)
- Save pending manuscript edits automatically before chapter/project switching, opening the event editor or otherwise leaving writing. Navigate only after durable acknowledgment. Failure warns, retains editor/edits and pending navigation, and offers Retry or Cancel navigation. [DEC-15](../../../../specs/spec-WritingTool/contracts.md#automatic-save-before-manuscript-navigation--dec-15)
- Chapter start/end are optional and independently editable. Inverted complete ranges set end equal to start; chapter changes and chapter-only restoration preserve linked event dates/content. Show linked events and an **Edit event** link to the dedicated canonical event editor; do not edit events inline or offer chapter-driven shifting controls. Same-universe birth/background events can link to multiple chapters; each chapter/event pair has one main/flashback role. Selected timeline date prefills only a new event's editable date. [Chapter/event contract](../../../../specs/spec-WritingTool/contracts.md#chapter-dates-and-event-editing), [DEC-01](../../../../specs/spec-WritingTool/contracts.md#chapter-end-before-start-correction--dec-01), [DEC-24](../../../../specs/spec-WritingTool/contracts.md#chapterevent-link-eligibility-and-entry-defaults--dec-24-resolved)
- Timeline explicitly identifies its universe; universe/timeline selection synchronizes by ownership. Chapter focus uses both dates' range, a lone date as a point, or retains current view when undated. Out-of-period linked events remain listed with **Go to event** / **Return to chapter period**, changing view only. [FR-44/45](../../../../specs/spec-WritingTool/requirements.md), [DEC-25](../../../../specs/spec-WritingTool/contracts.md#chapter-timeline-focus-and-out-of-period-navigation--dec-25-resolved)
- Maker is at most one existing same-universe character or faction, distinct from explicit “relevant to” character/story associations. Character context uses its explicit associations; story context uses its story associations; writing context unions selected-story and chapter-character matches and deduplicates canonical decisions. Maker/date/proximity alone establishes no relevance. [DEC-26](../../../../specs/spec-WritingTool/contracts.md#decision-contextual-associations-and-relevance--dec-26-resolved), [Story 4.7](../../../epics.md#story-47-inspect-established-decisions-in-character-story-arc-and-writing-context)
- Decision trees show established directed decision→decision and decision→event links. Any outgoing result link resolves its source; incoming links alone do not, and status does not propagate. Reject earlier-date result/following links, self-links and cycles with clear errors and no date shifts. Unresolved lookup is timeline-accessible and includes position/maker/decision. [DEC-27/28](../../../../specs/spec-WritingTool/contracts.md#decision-result-event-eligibility-and-chronology--dec-27-resolved), [FR-32/33](../../../../specs/spec-WritingTool/requirements.md)

## Filters and types

- Initially show all makers/categories; OR within maker/category selections, AND across groups. Persist per universe and synchronize timeline, tree, writing context and unresolved lookup. Existing context constraints continue to apply. Show active-filter indicator, **Show all** reset and **Hidden by filters** relationship endpoints. Distinguish filtered results from unfiltered empty results; filters never change records, links, chronology or canonical resolution/unresolved membership. [DEC-29](../../../../specs/spec-WritingTool/contracts.md#dec-29--visibility-filters-approved-2026-10-17), [Story 4.7](../../../epics.md#story-47-inspect-established-decisions-in-character-story-arc-and-writing-context)
- Initial categories: Universe Events, Personal Decisions, Story Decisions. Main/flashback roles and linked/unlinked status are separate concepts. Personal requires maker; Story and Universe Events allow none. Custom universe-owned/shared decision types choose **Maker required** (default optional); nonblank names unique ignoring case/surrounding spaces, including built-ins. Type changes preserve content/links, enforce required maker at save, and never automatically associate stories. Makerless records display/filter as **No maker**, visible by default and hidden by selecting only named makers. Type rename/delete and arbitrary fields are not implied. [Category contract](../../../../specs/spec-WritingTool/contracts.md#timeline-categories-and-extensible-decision-types), [DEC-30](../../../../specs/spec-WritingTool/contracts.md#dec-30--custom-decision-types-and-makerless-records-approved-2026-10-17)

## Save, failure and recovery

- Independent autosave/revision/scheduled-backup defaults are 5/10/10 minutes. Timers start at project/eligible-unit open, restart on interval change, run one overdue attempt after sleep and do not overlap. Failures retain work/valid prior output, warn, offer **Retry now** and retry next interval. Scheduled backups target open projects and independently opened standalone universes; one alternative-folder prompt at a time. [DEC-17/31/34](../../../../specs/spec-WritingTool/contracts.md#periodic-autosave-timing-and-retry--dec-17)
- Backups permit available external-drive destinations independent of live roots. Outside close, canceling alternate folder skips only that attempt, reports incomplete with retry, preserves configured destination. On normal close, cancel uses new application-root backup folder then user-data fallback; next launch identifies actual folder and requests a destination. Any required save/revision/backup failure keeps app open, reports outcomes separately and offers **Retry**, another backup folder where applicable, **Cancel closing**. [FR-25/26](../../../../specs/spec-WritingTool/requirements.md), [DEC-08](../../../../specs/spec-WritingTool/contracts.md#normal-close-failure-and-retry--dec-08)
- View/restore individual chapter/character/event revisions or whole-project revisions. Protective viewable/restorable **Replaced** revision must succeed before restoration. Chapter restoration never changes linked events. Complete ZIPs are independent recovery sources; failed/incomplete archives are not success. Default retention is 30 elapsed days, oldest eligible first, protecting current/retained dependencies and ten newest valid ZIPs per project/standalone universe, including against manual deletion. No fixed minimum revision count. [FR-2–4/18–26](../../../../specs/spec-WritingTool/requirements.md)
- Missing live universe offers locate folder or recover backup; keep project inactive until matching single authority exists. Resolve conflicts manually: **Keep live**, **Use recovered**, **Edit combined**; apply only after confirmation, affecting all sharing projects. Resolve missing references by restore missing record/link same-universe replacement/remove reference before activation. Cancel preserves resumable work, leaves live data unchanged and restored project inactive. Refresh affected conflicts if live authority changes; preserve unaffected choices. [Recovery contracts](../../../../specs/spec-WritingTool/contracts.md#missing-universe-authority)
- Restored calendar mismatch stays visibly flagged across reopening. **Update to current calendar** recalculates display from preserved elapsed positions, preserves writing/relationships/authority, and clears flag only after save success. Failure retains flag with retry; writing remains available while pending. [DEC-32](../../../../specs/spec-WritingTool/contracts.md#restored-calendar-update-workflow--dec-32-accepted)

## Export

- One story at a time; four formats DOCX/PDF/MD/TXT; all chapters or selected chapters in story order. Include titles/text and titled empty chapters; exclude dates/planning/context. Clear scope/format before output; disable with explanation if no chapters/no selection. Save pending edits before capture; save failure offers retry/cancel. [DEC-06 selection](../../../../specs/spec-WritingTool/contracts.md#dec-06--manuscript-export-selection-and-capture-approved-2026-10-17-partial-decision), [Story 6.1](../../../epics.md#story-61-export-a-whole-story-or-selected-chapters-as-docx-pdf-markdown-or-text)
- DOCX/PDF retain rich formatting, chapter-title/new-page boundaries, A4, 2.54 cm margins, 12-point serif and 1.5 spacing. Markdown bold/italics/headings with no paragraph indents; TXT plain titles/text, four-space indents, no bold/italic markers. Preserve paragraph breaks; literal `***` scene breaks in all formats. [DEC-06 formatting](../../../../specs/spec-WritingTool/contracts.md#dec-06--manuscript-export-formatting-approved-2026-10-17-partial-decision)
- **Save As** suggests `<StoryName>.<extension>` or `<StoryName>_selected-chapters.<extension>`, replaces filename-invalid characters, matches extension. Confirm replacement; declining returns to Save As. Publish after conversion succeeds, preserve existing output on failure. Error offers **Retry**, **Choose another location**, **Cancel**; success shows path with **Open file** / **Open folder**. Distinguish cancellation/failure/success and never claim partial output complete. [DEC-06 destination](../../../../specs/spec-WritingTool/contracts.md#dec-06--manuscript-export-destination-and-publication-approved-2026-10-17-partial-decision), [Story 6.1](../../../epics.md#story-61-export-a-whole-story-or-selected-chapters-as-docx-pdf-markdown-or-text)
- Bundle headless LibreOffice for local DOCX/PDF, no separate installation/service; own TypeScript serializers for MD/TXT. Earlier docx/Electron-printToPDF proposal is superseded. Engine/runtime details are implementation constraints, not additional user-facing controls. Export does not become backup or database/settings export. [Resolved DEC-06](../../../../specs/spec-WritingTool/contracts.md#dec-06--bundled-libreoffice-export-engine-approved-2026-10-17-decision-resolved)

## Themes and structured editing

- Light/dark/system; system follows OS changes. Theme survives settings export/import. Independent intervals accept positive whole minutes and retention positive whole days; invalid known settings reject entire import with no partial change, missing fields retain values, unknown fields warn/ignore, unavailable backup location may remain configured. [FR-28–30](../../../../specs/spec-WritingTool/requirements.md), [DEC-07](../../../../specs/spec-WritingTool/contracts.md#settings-validation-and-atomic-import--dec-07-resolved)
- Character expected prompts have answered/incomplete/explicit-waiver states without save barriers; name cannot be waived. Type changes preserve answers/waivers. Personality selector uses names only from exact supplied 100-label catalog with zero/one/many selections. Images validate PNG/JPEG/WebP, preserve prior image on failed import and display fitted aspect ratio without crop/stretch. Faction incomplete drafts save; affiliation history stays character-sheet-only. [FR-15–17/36–39/48](../../../../specs/spec-WritingTool/requirements.md), [DEC-05/18](../../../../specs/spec-WritingTool/contracts.md#character-waiver-state-transitions--dec-05-partial-decision)
- Calendar supports day-count/year-number minimum, optional named months/standalone days/year names, unbounded exact signed years including zero and date-only chronology. Mismatch target is visibly red vs green match but save permitted with target corrected to actual. Accepted standalone-day display matrix is already resolved, not a fresh discovery gap. [FR-7–13/display examples](../../../../specs/spec-WritingTool/requirements.md), [DEC-04](../../../../specs/spec-WritingTool/contracts.md#complete-standalone-display-matrix--dec-04-resolved)
