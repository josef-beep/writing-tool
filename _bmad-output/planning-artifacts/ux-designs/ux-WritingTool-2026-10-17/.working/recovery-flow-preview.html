Leaving with unsaved combined edits: Save proposal / Discard / CancelSave proposal must validate and record successfully, then follows the next-unresolved-conflict/close-editor progression. Failure retains the editor and edits. Discard abandons only current unsaved combined edits, preserves both sources and recorded choices, and leaves the conflict unresolved unless an earlier valid choice remains. Cancel stays with the edits. This describes prompt behavior without selecting a prompt container or visual style.

Before recovery activation, preserve the accepted missing-reference resolution, schema validation, protective history, freshness rechecks, authority and explicit confirmation gates.
