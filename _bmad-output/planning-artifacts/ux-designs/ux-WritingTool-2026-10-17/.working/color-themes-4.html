Focus outlines are forced samples, not an implemented focus system. Status success examples reflect only actual durable outcomes in the app. Warning/failure samples belong to the approved blocking dialog workflow; center manual progress and bottom calendar/status placement remain.

Engineering target: normal text ≥4.5:1; specified essential boundaries/focus ≥3:1 against their actual compared surfaces, including gray editor separately. Ratios use sRGB relative luminance and unrounded pass/fail decisions. See W3C contrast reference and machine-readable candidates/pairs. This checks declared color pairs only, not full WCAG certification, assistive-tech behavior, system font rendering, OS focus or scaling. Native system text scaling/reduced-motion and screen-reader labels remain implementation/acceptance requirements. No JavaScript, network, hosted service or application behavior is provided.
